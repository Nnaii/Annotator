✨ Аннотатор научных статей (Powered by Mistral AI)

Описание:

Данная программа предназначена для автоматизации процесса создания научных аннотаций и их последующего перевода на английский язык. Инструмент анализирует содержимое статьи и формирует структурированный текст (актуальность, цель, методы, результаты, выводы), соответствующий академическим стандартам.

Основные возможности:

- Поддержка форматов: Извлечение текста из файлов .pdf, .docx и .txt.
- Обработка больших документов: Система «нарезки» (chunking) позволяет обрабатывать даже очень длинные статьи без потери контекста.
- Академический перевод: Перевод аннотации на английский язык с использованием специализированного научного стиля (Academic English).
- Конфиденциальность: Обработка текста происходит через API, без сохранения ваших данных на сторонних серверах.

Инструкция по использованию:

1. Запустите файл main.exe.
2. Нажмите кнопку «Выбрать файл» и выберите вашу статью.
3. После автоматического извлечения текста вы можете отредактировать его в верхнем окне, если это необходимо.
4. Нажмите «Создать аннотацию» - подождите, пока ИИ обработает текст (статус будет отображаться внизу).
5. Нажмите «Перевести», чтобы получить англоязычную версию.
6. Нажмите «Сохранить», чтобы выгрузить результаты в текстовые файлы.

Технические требования:

- Для работы программы требуется стабильное интернет-соединение.
- Программа использует API Mistral AI.
